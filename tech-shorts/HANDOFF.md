## 1) الفكرة

## 2) الهوية البصرية المعتمدة — «الستايل C»
رسم مسطّح بخطوط (editorial flat) متل القناة المرجع، بس كحلي. **كل العناصر متحركة بالكود، وممنوع أي صورة ثابتة.**

| الدور | اللون |
|---|---|
| الخلفية | `#0F2436` كحلي + شبكة نقاط `#1C3448` + حبيبات فيلم |
| الخطوط / النص | `#F1EEE5` كريمي |
| اللون المميّز (الكلمة المفتاحية، الطوابع) | `#FFD43B` أصفر |
| اللون التاني | `#62D9B5` نعناعي |
| لون تالت | `#F59AC0` وردي (قليل) |
| الكروت | `#152C40` مع إطار كريمي 5–7px وظل صلب مزاح |

- **الخطوط:** العنوان Noto Naskh Arabic 700، والواجهة والكابشن Readex Pro 400/600. الملفات محلية بـ `public/fonts`.
- **ثابت بكل فيديو:**
  - فوق يسار: «طيب شلون؟» مع المربع الأصفر.
  - فوق يمين: التصنيف بإطار أصفر.
  - العنوان سطرين، كلمة كلمة، والكلمة المفتاحية بالأصفر، وتحته خط أصفر.
  - **توقيع حماية بنص الكادر:** «طيب شلون؟ · محمود أعرج».
  - الكابشن تحت، الكلمات بتنكتب مع الحكي، والكلمة الحالية صفرا مع خط.
  - الخاتمة: كرت جملة الختام بظل أصفر، والشعار، و«إعداد وتقديم: محمود أعرج».
- **قواعد الحركة:** Bezier easing فقط، ممنوع Linear. **Motion Blur** على الكومبوزيشن كله (CameraMotionBlur، 4 عينات، shutter 180). عمق بطبقتين (خلفية بطيئة + رئيسية) مع دفع كاميرا بطيء، وزوم مع هزّة بلحظات الصدمة.
- **مرفوض:** البرتقالي، والكريمي الفاتح كخلفية، وستايل النيون الزجاجي التلاتي، والصور المولّدة الثابتة مع حركة كاميرا بس (جرّبناهم وانرفضوا).

## 3) بصمة الصوت — الدليل الكامل
- **المنصة:** HeyGen API.
- **اسم الصوت:** `Mahmoud - Syrian Narrator`
- **voice_id:** `2cd2b20e640f466bba3c4fb47f61827c` (Instant Clone، لغة `ar`، ذكر)
- **انعمل من:** تسجيل 72 ثانية بصوت محمود (m4a ← wav 44.1kHz mono)، `similarity: extra_high`، `remove_background_noise: true`.
- **المفتاح:** محفوظ كـ Network secret على بيئة Claude لـ `api.heygen.com` بالهيدر `X-Api-Key`. **ما ينكتب بالكود ولا بالمحادثة.**

### توليد الكلام
```
POST https://api.heygen.com/v3/models/audio/tts
{
  "model": "heygen-voice-1-turbo-free",   // مجاني لـ 30 نوفمبر 2026
  "voice_id": "2cd2b20e640f466bba3c4fb47f61827c",
  "language": "ar",
  "text": "...",
  "with_timestamps": true,
  "expressiveness_boost": 1.0
}
```
- الرد فيه `audio_url` (WAV) و`duration` و`original_characters` (توقيت كل حرف، ومنه منطلّع توقيت الكلمات للكابشن والحركة).
- الموديل الأقوى `heygen-voice-1` بدو **رصيد API** منفصل عن اشتراك الموقع (حالياً الرصيد 0).

### قواعد كتابة النص للصوت (مهمة لنطق صح)
1. **مشهد واحد = ملف صوت واحد**، جمل قصيرة.
2. المصطلحات الإنكليزية بحروف عربية: «إس إس دي»، «تاسك مانيجر»، «واي فاي».
3. الأرقام بالكلمات: «إتناعش»، «مية»، «تمانية».
4. الكلمات المتشابهة بالصوت تتفرّق بوضوح: «ميغا بِت» / «ميغا بايت» (منفصلين).
5. فواصل ونقاط للوقفات، والتشكيل على الكلمات الملتبسة.
6. إذا بدك تغيّر الحكي بدون ما يتغيّر الكابشن: حقل `"tts"` بالمشهد.

### فحص النطق التلقائي
- كل مقطع بيرجع ينكتب نص بـ **Whisper medium** وبينقارن كلمة كلمة مع السكريبت (مع توحيد فروقات اللهجة: لحالو/لحاله، متل/مثل، ث/ت…).
- تحت 0.82 بيعيد مرة بإلقاء أهدى (`expressiveness_boost: 0.6`) وبيحتفظ بالأوضح.
- الأداة: `python3 tools/gen_voice.py` (بتكمّل من وين وقفت، وبتوقف لحالها عند الحد اليومي).
- **الحالة:** أصوات الـ 30 حلقة كلها جاهزة بـ `public/vo/epXX/sNN.mp3` و`.json`.

## 5) التقنية (Remotion)
| الملف | الوظيفة |
|---|---|
| `src/Root.tsx` | بيعمل كومبوزيشن لكل حلقة، وبيقرا مدة كل مشهد من ملف الصوت |
| `src/Episode.tsx` | الإطار، العنوان، الكابشن، التوقيع، الخاتمة، الـ Motion Blur، تراك الصوت |
| `src/theme.ts` | الألوان (`midnight` = الستايل C)، الخطوط، الـ easing |
| `src/scenes/kit.tsx` | قطع متحركة جاهزة: Monitor، Laptop، Phone، Router، Waves، Virus، Cursor، Stopwatch، Gauge، Progress، Chip، Strike… |
| `src/scenes/Ep01Flat.tsx` | `Rig` (الكاميرا والعمق)، `Sign`، `Stamp`، `Desk`، `Cabinet`، `Tool`، و`useCue` |
| `src/scenes/EpXXFlat.tsx` | مشاهد كل حلقة |
| `src/scenes/registry.tsx` | اسم المشهد ← المكوّن (الـ JSON بيشير للمشهد بـ `{"type":"custom","scene":"اسم"}`) |

**أهم قاعدة:** كل حركة مربوطة بكلمتها عن طريق `useCue(words)("كلمة", fallback)`، فلما يتغيّر الصوت كل شي بيتزامن لحاله.

**المشهد** = منصّة 1000×1000 جوّا `<Rig>`. خلّي العناصر بين y≈90 و y≈820 حتى ما تغطي الكابشن والتوقيع، وبين x≈190 و x≈810 حتى ما تنقص.

### الأوامر
```bash
cd tech-shorts && npm i
python3 tools/gen_voice.py                  # أصوات
node tools/cues.mjs                         # Markers للـ SFX والموسيقى → public/cues/epXX.csv
npx remotion studio                         # معاينة
node tools/stills.mjs ep06 /tmp/s midnight 60,300,600   # لقطات فحص سريعة
npx remotion render src/index.ts ep06 out/ep06.mp4 --concurrency=4 --crf=18
```
- على السيرفر السحابي الرندر بياخد 8–13 دقيقة للحلقة بسبب الـ Motion Blur. على جهاز فيه كرت شاشة أسرع بكتير.
- للمعاينة السريعة بدون Blur: `--props='{"motionBlur":false}'`.
